# 剑桥中译英 iPad PWA V0.2（增量批改版）

## 版本定位

基于《剑桥初级英语语法》第三版的离线PWA训练原型。115课索引，**仅第1—65课共195道原创题**；每课A/B/C各1题。**题库仍不足以长期使用，尚未完成全量逐题人工校对，01不能冻结**。Unit 66—115没有题目。无需付费AI API。

## 运行与安装

将整个文件夹部署到HTTPS静态网站（如GitHub Pages）；Safari打开网址 → 分享 → 添加到主屏幕。首次在线加载并安装缓存后可离线答题。不要直接在iPad文件App中双击index.html（`file://` 不支持正常缓存和数据访问）。

## 每轮流程

1. PWA本地根据进度和复习权重抽10题，直接输入英文。
2. 可在下拉菜单选择目标词逐级提示（只覆盖题库已配置词汇）；其他想不起的中文词可在输入框标记。
3. 完成答卷，进入4页批改截图（每页最多3题）。**推荐点击“复制完整批改文本”粘贴给ChatGPT**，可避免截图识别误差。
4. ChatGPT按`docs/02_AI_protocol.md`批改，仅生成本轮结果JSON（`02_result_...json`），无需重写03。
5. 在PWA点击“导入本轮批改JSON”，iPad原生文件选择器选择该JSON；程序校验批次、版本、题号、评分、反馈和词汇提取等级，合并到本地03。
6. 在“数据与设置”中定期**导出完整03.md备份**，不要只依赖Safari本地存储。

## 三部分结构

- 01：`data/01_question_bank.json`（目前是有限原型题库，非最终版）。
- 02：`docs/02_AI_protocol.md`（增量批改规则与结果JSON接口）。
- 03：PWA的IndexedDB完整历史；导出为单个`03_剑桥语法_学习进度.md`文件；AI只生成本轮结果，PWA本地合并更新03。

## 数据安全

导入本轮结果时先保存旧状态到IndexedDB的`rollback_<revision>`记录，再合并。若错误导入，可使用之前导出的03备份恢复。放弃本轮会先导出含待处理答卷的JSON，再清空待处理状态。旧版V0.1本地03 schema 3.0支持启动时迁移至3.1，但**旧版完整03导入批改方式已取消**；完整03仅用于备份恢复。

## 已知限制

- iPad Safari真机安装和离线长期持久性仍需实测。
- 题库每课只有3题；A级两次跨日通过才解锁B级，题目重复率较高。
- 词汇提示依赖01内已配置的词；自由输入的其他词只记录不会，无法离线给出可靠提示。
- 题库的`verified`字段为`needs-human-audit`，仍需全面逐题人工复核。
- PWA不内置AI，ChatGPT需要用户手动复制文本或截图，再将结果JSON保存到文件App导入。
